Qualitative coding software

Code interview transcripts on a visual canvas.

QualCanvas is for students, academics and research teams who analyze interviews. Highlight a passage and tag it with a code. Then drag codes into themes and write memos beside them, in your browser.

What it does

  • Visual coding canvasHighlight a span, name a code. Move it. Merge it. Split it. The way real coding actually goes.
  • Intercoder reliability liveCohen's κ and Krippendorff's α calculated as your team codes. Methods-paper-ready CSV export.
  • Ethics & consent built inTrack consent, anonymize fields, record a data-retention date per project. The audit trail your IRB will ask for is already running.
  • QDPX in and outImport from NVivo or ATLAS.ti. Export back any time. No lock-in by design.
