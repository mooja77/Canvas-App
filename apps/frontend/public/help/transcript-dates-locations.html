Add dates and locations to a transcript

These optional details help you compare when and where events happened. Skip them if your research does not need a timeline or location plot. They do not change your interview text or saved codes.

  1. Open your project. Choose Tools → Transcript dates and locations. You can also open this editor from an empty timeline or location plot.
  2. Choose the transcript. Wait for its saved details to load. If loading fails, choose Check saved details; do not guess what was saved.
  3. For a timeline, enter the event date and time in UTC. This is the interview or event date, not the date you imported the file. Leave it blank if you do not know it.
  4. For a location plot, enter both latitude and longitude, or leave both blank. Use coordinates you already know and have permission to record. QualCanvas does not look up locations.
  5. Add an optional broad location label. Avoid identifying a participant's home. Choose Save transcript details and wait for the saved-and-checked message.
  6. Return to the timeline or location plot and choose Run. Existing analysis results do not update until you run them again.

A fictional example

For an invented event at noon UTC on 7 October 2026, enter that date and 12:00. An approximate Cork city coordinate example is latitude 51.9, longitude −8.5, with the label “Fictional Cork event”. This example is not a participant's address and is not added to your project automatically.

If a save cannot be confirmed

Your typed entries remain on screen. Check saved details only reads; it never repeats a save. Compare “Last verified saved details” with your entries. Save again only if you still want those changes.

Removing details

Clear the date to remove it from timeline analysis. Clear both coordinates to remove it from the location plot. Save and run the analysis again. The transcript and codes remain.

The location plot shows relative coordinates, not a street map. A viewer can read details but cannot change them.
