# QualCanvas feature map

Estate Test Programme, Wave 4, 26–27 Sep 2026, branch `qa/estate-20260926`.

**Sources.** Features were collected from four places:

- the code: 181 route handlers across 32 files in `apps/backend/src/routes`, mounted under `/api` and `/api/v1`, plus the pages and panels in `apps/frontend/src`;
- the website (qualcanvas.com, `/guide`, `/for-teams`, `/trust`) and its frontend source;
- the pricing page (`PricingPage.tsx`, which matches the live `/pricing`);
- `README`/`docs/*.md`/`CLAUDE.md`.

**Status key.**

- **FS**: the new full-stack suite `e2e/fullstack` covers it. That suite runs the real backend and frontend on a local Postgres, with no outbound traffic.
- **SIM**: the 12-month simulation exercises it and checks invariants.
- **E2E**: the existing browser suite covers it (`e2e/*.spec.ts`, 735 tests).
- **UNIT**: backend and frontend unit/integration tests cover it.
- **GAP**: nothing exercises it end to end.

Final pass counts are in `ESTATE-FINDINGS-2026-09-26.md`.
