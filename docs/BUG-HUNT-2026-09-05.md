## Verified clean

Auth rate limits on every auth endpoint (10 / 15 min); `trust proxy` set to 1 so limits key on the real client IP; graceful SIGTERM shutdown; reset and verification tokens hashed, expiring, cleared on use, timing-safe compared; Stripe webhook signature verified and event ids deduplicated; share codes from `nanoid` with server-validated expiry; uploads capped by size and media type; AI settings never return the key; plan limits enforced server-side on every transcript path; viewer write guard covers the coding, transcript, computed and share routers (mounted inside `canvasRoutes`); CORS does not reflect arbitrary origins; HSTS, nosniff, referrer and permissions policies present on both hosts; every sitemap URL returns a direct 200; robots blocks `/canvas`, `/account`, `/admin`, `/api/`, token pages; i18n key sets identical across en/es/fr/de; no `console.log` in shipped frontend code; every `prisma.*` write flagged as unawaited is inside `Promise.all` or `$transaction`; localStorage access in `CanvasWorkspace` is try-wrapped; onboarding v2 defaults on and its first checklist item is "add a transcript".

## Improvement search

Ordered by what the activation funnel says matters (11 projects -> 6 transcripts -> 6 coded).

1. **Fix H1 and retire the stale pages (M1, M2).** Cheap, and the only findings a prospective user can hit today.
2. **Use the bulk import endpoint from the upload modal (M4).** A folder-of-interviews import becomes all-or-nothing with a real error message, which is the step the funnel loses people at.
3. **Revive the demo (H2).** It is the one path that lets someone see a coded canvas without an account. Needs a prod write.
4. **Free-plan word cap vs interview length.** The cap is 10,000 words per transcript. A 60-minute interview at ~150 wpm is roughly 9,000-10,000 words, so some first-time imports will be refused at the exact step the funnel loses people. **Unproven**: no real transcript lengths were measured. Measure word counts of the real transcripts in prod (`/admin/users/:id` usage) before touching the cap.
5. **Dependencies (M5), CSP (L3), DMARC (L2), indexes (L1), test robustness (L4).** Housekeeping; none user-visible.
6. **`.xlsx` import** stays deferred until a pilot user asks (decision 2026-09-05).

## Method notes

- Production data first: admin health/dashboard/activity, Railway logs, Actions history, E2E log.
- HTTP probe of 25 marketing paths and 6 API paths; sitemap walked URL by URL.
- Static pages' claims grepped against the codebase one by one; `integrations.html` turned out to be already honest, which corrected an early assumption that it still advertised account integrations.
- Browser sweep of `/`, `/pricing`, `/features`, `/login` for console errors (none), then a demo login attempt (H2). The canvas itself could not be exercised live: the demo is dead and no other credential is appropriate to use. E2E on main covers it (726 green).
